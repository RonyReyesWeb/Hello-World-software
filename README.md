# Overview

As a junior software engineer, I set up this project to confirm my development
environment and practice the workflow I use for every new technology:
write code, document it, demo it, and publish it.

The program prints "Hello World", asks for the user's name, and greets
them based on the time of day in English and Spanish.

My purpose was to verify Python, Git and GitHub work end to end before
taking on larger projects.

[Software Demo Video](https://www.youtube.com/watch?v=ArUJpKQKATs)

# Development Environment

- Visual Studio Code
- Git and GitHub
- Python 3 (standard library only: `datetime`)
